# tbb1.3.1 - Trimui Brick 4:3 现代化掌上阅读器

专为 **Trimui Brick 掌机**（3.2 英寸 1024×768、4:3 IPS 超视网膜屏、无触屏纯手柄按键）定制的高颜值、现代化轻量级电子书与漫画阅读器。

---

## 🌟 核心特色与新增功能

### 1. ⚙️ 全新「设置中心」与「书库目录浏览器」
* **自定义书库目录选择**：内置可视化文件/文件夹浏览器，支持自由浏览、进入子目录（`📁 [ .. 上级目录 ]`），一键将任意目录（如 `/mnt/SDCARD/Roms/BOOKS`、`books/`、自定义 TF 卡文件夹）设为当前扫描书库。
* **全局字体大小调节**：在设置中心或阅读过程中以 2px 步进自由调整默认字号（18px ~ 48px），并自动重新排版与分页。
* **默认行距调节**：支持 1.1x ~ 2.2x 动态行距调节。
* **配置自动持久化**：所有个性化配置（书库路径、字号、主题、日漫/国漫顺序、RGB 开关）自动保存至 `data/settings.json`。

### 2. 现代化极简与磨砂 UI 视觉
* **7 款精美主题**：除羊皮纸、竹青、深空黑和纯黑漫画外，新增宣纸灰、松墨绿、琥珀夜三套低对比/低蓝光护眼主题。
* **现代卡片式书架**：自动提取小说/漫画封面、格式徽章（TXT / CBZ）、文件大小、当前扫描目录与精确到百分比的阅读进度条。
* **磨砂浮动控制底栏（Bottom Floating Dock）**：按下 `Menu` 键平滑呼出半透明控制浮层。
* **真实系统状态**：读取 TrimUI 的 `axp2202-battery` 电量与充电状态；接口不可用时自动隐藏，不显示模拟电量。
* **硬件联动**：背部/肩部 RGB 氛围灯根据当前主题自动变换色调（夜间自动熄灭，日间温暖琥珀）。

### 3. 漫画与图像专业阅读引擎
* **自由与平滑多级缩放**：支持连续缩放（`R2` 放大 / `L2` 缩小）以及适应全屏、适应宽度、适应高度快切。
* **无摇杆按键视窗平移漫游 (Pan)**：在放大状态下（Zoom > 1.0x），十字键自动切换为**视窗上下左右平移漫游**（带长按加速度微调与边界碰撞阻尼）。
* **翻页不打断**：在画面放大状态下，`L1 / R1` 肩键依然保持极速翻页。
* **右上角鹰眼小地图（Minimap）**：移动画面时自动浮现微缩位置指示器。
* **日漫/国漫顺序切换**：支持 🇯🇵 **日漫（RTL 从右向左）** 与 🇨🇳 **国漫/美漫（LTR 从左向右）** 自由切换。
* **智能切白边**：一键裁切扫描件多余黑白边缘，画面填满 4:3 屏幕。

### 4. 小说文本专业排版
* **原生 EPUB 支持**：解析 EPUB 容器、OPF 书脊和 XHTML 正文，不再把 EPUB 压缩包误当作 TXT 解码。
* **中文避头尾算法**：标点不落行首、开括号不落行尾、段首自动全角两格缩进。
* **智能编码探测**：彻底告别 UTF-8、GBK、GB18030、UTF-16 乱码。
* **章节自动识别与跳转**：智能识别中英文章节标题，阅读页常驻显示章节名；按 `Select` 或 `Start` 打开目录，上下选择后按 `A` 跳转。
* **常驻阅读进度**：底部显示当前页、总页数、精确百分比和全宽进度条，最后一页正确显示 100%。

## 🚀 编译与运行

### 1. 本地模拟器运行（Windows / macOS）
```bash
cargo run
```
即刻弹出 **1024×768（4:3 比例）** 的 Trimui Brick 模拟器窗口，使用键盘即可模拟全部掌机操作。

> Linux 构建默认启用掌机的 `/dev/fb0` + evdev 后端，不会打开桌面窗口。

### 2. 打包到 Trimui Brick 掌机
```bash
./build_trimui.sh
```

脚本会运行测试、使用 `aarch64-unknown-linux-musl` 构建完全静态的 ARM64
程序，并确认产物没有动态加载器或共享库依赖。不要改用发行版自带的
`aarch64-linux-gnu-gcc` 直接打包；它可能生成要求较新 GLIBC 的程序，在
TrimUI 上点击后会立即退出。

构建完成后，把 `package/Apps/BrickReader` 整个目录复制到 TF 卡的
`Apps/` 下。以 Windows 中 TF 卡为 F: 为例，最终入口应为：

```text
F:\Apps\BrickReader\config.json
F:\Apps\BrickReader\launch.sh
F:\Apps\BrickReader\bin\brick_reader
```

若启动仍失败，查看 TF 卡上的 `F:\Apps\BrickReader\log.txt`；启动脚本会
记录内核、framebuffer 是否存在以及程序退出码。
